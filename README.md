# Site de Marketing (Landing Page)

Este repositório contém uma landing page de marketing inspirada em um layout de referência, com visual moderno em tema escuro.

## ✨ O que foi implementado

- Header com logo, navegação e campo de busca.
- Hero principal com título de impacto e subtítulo.
- Área de oferta com CTA (botão de ação) e ícones sociais.
- Bloco lateral com informações de localização e texto institucional.
- Elementos visuais decorativos (glows e blob) para reforçar o estilo.
- Layout responsivo para telas menores.

## 📁 Estrutura

- `index.html`: estrutura da página.
- `styles.css`: estilos visuais e responsividade.

## 🚀 Como executar localmente

No diretório do projeto, rode:

```bash
python3 -m http.server 4173
```

Depois, abra no navegador:

- http://localhost:4173

## 🛠️ Tecnologias

- HTML5
- CSS3

## 📌 Observações

Este projeto é estático (sem build tool e sem dependências externas de framework), ideal como base para páginas promocionais e campanhas.
